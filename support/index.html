Subscriptions and restore

Premium and Pro are optional monthly or yearly subscriptions billed by Apple. Manage or cancel them in your Apple Account subscriptions. In LEEBI, open More → Subscription → Restore purchases using the same Apple Account. If prices are unavailable, check your internet connection, reopen the app and contact us.

Pro PC connection

Connect the iPhone and computer to the same trusted Wi-Fi. In More → Use on PC, start the connection and enter the displayed address and six-digit code in a PC browser. Keep this screen open. Leaving it or backgrounding LEEBI stops the connection. HTTP is not encrypted; do not use public Wi-Fi.

Records and backup

Records stay on your device. JSON backups include all currency books but exclude photo files and your app-lock PIN. Save backups before changing or reinstalling the app. Review the import preview before restoring.

Reminders and permissions

Allow Notifications and select a future date and time for reminders. Check Focus and notification settings if a reminder is not shown. Camera, Photos, Location, Face ID and Local Network permissions are used only for their respective features.

Markdown

Pro includes note editing and preview with Markdown, plus .md import and export in Backup. Files you export contain the selected note content; share them only with people you choose.
